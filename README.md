# Siesta Lab

Static website for Siesta Lab.

Website: https://siestalab.github.io/

## Publish

Use the public `siestalab/siestalab.github.io` repository. Enable GitHub Pages with **Deploy from a branch**, select `main`, and select `/(root)`.
The `.nojekyll` file allows the HTML, CSS, JavaScript, and SVG files to be served directly.

The home page is `index.html`; member pages are in `people/`. Internal links are relative and work from the site root.
